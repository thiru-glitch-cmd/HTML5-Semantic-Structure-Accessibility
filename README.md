# Personal Portfolio Website – Semantic HTML5 & Accessibility

##  Project Overview

This project is a fully accessible and SEO-friendly multi-page personal portfolio website built using modern HTML5 semantic elements and CSS. The website follows WCAG accessibility guidelines and incorporates best practices for usability, navigation, and search engine optimization.

The portfolio showcases personal information, skills, projects, and contact details through a clean and responsive design.

---

##  Features

### Semantic HTML5 Structure

* Uses semantic elements such as:

  * `<header>`
  * `<nav>`
  * `<main>`
  * `<section>`
  * `<article>`
  * `<footer>`

### Accessibility (WCAG Compliant)

* ARIA labels for enhanced screen reader support
* Skip-to-content navigation link
* Keyboard-accessible navigation
* Proper heading hierarchy
* Accessible contact form with labels and validation
* Focus indicators for keyboard users

### SEO Optimization

* Descriptive page titles
* Meta descriptions
* Responsive viewport settings
* Clean and structured HTML markup

### Responsive Design

* Mobile-friendly layout
* Flexible navigation menu
* Responsive sections and forms
